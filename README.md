# Agro Solutions — React + Vite website sample

A responsive front-end concept for an India-focused agrochemical / agricultural solutions company.

## Run locally

1. Install Node.js (LTS) if it is not already installed: https://nodejs.org/
2. Extract this project folder.
3. Open a terminal inside the `agro-solutions` folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL Vite prints (usually `http://localhost:5173`).

For a production build:

```bash
npm run build
npm run preview
```

## What's included

- Responsive React + Vite single-page website
- Sticky navigation with an Explore dropdown
- Hero section, company story, values, product catalogue, crop-care guidance, contact form and footer
- Filterable sample product cards and product detail modals
- Mobile navigation and responsive layouts
- Lucide icons

## Important before showing/publishing to the client

- "Agro Solutions" and all product names/details are placeholders for a concept.
- The contact form currently validates in the browser and shows a demo confirmation only. It does not send data. Connect it to the client's backend, CRM or form provider before production.
- Replace the sample phone number, email, address/service claims, company history, and product details with verified client information.
- Product artwork is CSS-generated concept packaging. It is not real packaging or a label.
- Verify all pesticide/agrochemical product registrations, label claims, crops, directions, and safety statements with the client and applicable Indian regulations before publishing.
- Hero and about photos are loaded from Unsplash over the internet. Replace with client-owned/licensed imagery if required.
- The Google Fonts link also requires an internet connection.
